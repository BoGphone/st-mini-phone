# 📱 小手机

SillyTavern 扩展。一部只给你自己看的手机：偷看角色的日程、地图、随机事件、本地小红书和 X 浏览记录。内容由 AI 按角色卡、世界书和剧情生成，**不会发给聊天模型，不占 token**。

## 功能

- 🗓 **日程**：整月日程、节日与假期、生日与纪念日（识别一次就固定，每年显示）
- 🗺 **地图**：按世界书画出故事所在的城市，图钉、区域、「你在这」、可拖动编辑；按角色卡保存
- 🎲 **随机**：本月可能发生的随机事件，可收藏、可划掉
- 📕 **小红书**：只看世界观的种草笔记流，带评论区
- 𝕏 **X**：角色私下刷 X 的浏览记录（偏成人向，默认打码）
- 🖼 **出图**：通过「柏宝绘」调用 NovelAI，给 X 帖子、小红书封面配图，或画手机壁纸
- 毛玻璃界面，可上传或生成壁纸；悬浮 📱 可拖动

## 需要

- **酒馆助手（JS-Slash-Runner）**：必须，生成和读取世界书都靠它
- **柏宝绘（ST-BaiBai-Image）**：可选，装了才能出图

## 安装

酒馆 → 扩展 → 安装扩展 → 填入本仓库地址。

## 打开

- 悬浮的 📱（可拖动，可在扩展设置里隐藏）
- 输入框左边的魔棒菜单 →「📱 小手机」
- 扩展设置里的「📱 小手机」面板

生成用的 API 默认是酒馆当前连接的，也可以在小手机的「设置」页里填独立 API。
