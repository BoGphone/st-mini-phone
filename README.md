# 📱 小手机

SillyTavern 扩展。一部只给你自己看的手机：桌面上一排 app，偷看角色的日程、地图、随机事件、本地小红书和 X 浏览记录，还有图鉴、百科、人物志这些跟着世界观变的 app。内容由 AI 按角色卡、世界书和剧情生成，**平时不会发给聊天模型，不占 token**；只有你点「📎 带进剧情」的那一条，才会附带给下一次回复。

## 功能

- 📱 **桌面**：app 图标网格，长按拖动换位置；左上角 ‹ 或从左往右划返回上一层，底部横条回桌面
- 🗓 **日程**：整月日程、节日与假期、生日与纪念日；月份和星期会按世界观起名（如「狩猎月」），底下还是 12 个月
- 🗺 **地图**：「这里」是故事所在的那片地方，图钉、区域、整张大背景图、可拖动编辑；「🧭 打听消息」会冒出还没去过的迷雾地点。「世界」是按世界书虚构的整个大陆，没去过的地方盖着迷雾，剧情里一提到就点亮（不使用任何现实地图）
- 🎲 **随机**：这个月可能发生的随机事件，可以选要不要出现新 NPC
- 📕 **小红书**：只看世界观的种草笔记流，带评论区
- 𝕏 **X**：角色私下刷 X 的浏览记录（偏成人向，默认打码）
- 📖 **图鉴**：RPG 式收集图鉴，没遇到的是「?」，剧情里一出现就自动点亮
- 🌿 **生活百科**：写给刚来到这个世界的人：吃什么、怎么做、有什么规矩
- 📜 **手记**：手机主人的随身手记；也可以切成「遗物书卷」，一页页解读前人留下的书，剧情里读懂才显示内容
- 📌 **委托**：软木公告板上钉着 NPC 的小委托，点开放大，做完自己标记完成
- 🔮 **占卜**：按这个世界的方式抽一签，给一句模糊的暗示
- 🌏 **蓝星online**：另一个和地球很像的世界里，网友把你的故事当成在追的作品来讨论；刷新时选 💘 梦向（把你当老婆、约稿、做周边、为你抽卡）或 🎮 一般向（聊剧情、考据、嗑 CP）
- 📇 **人物志**：每个人一张卡，你还不知道的事是「？」，剧情里说到就揭开；有关系网，知道的生日会记进日程
- 🖼 **出图**：通过「柏宝绘」调用 NovelAI，给帖子、图鉴、地点、人物等配图，或画手机壁纸
- 每个 app 右上角都是「🖼 一键生图」和「↻ 生成/刷新」；更新前会问「只新增」还是「全部重新生成」
- 毛玻璃界面，可上传或生成壁纸；悬浮 📱 可拖动

## 需要

- **酒馆助手（JS-Slash-Runner）**：必须，生成和读取世界书都靠它
- **柏宝绘（ST-BaiBai-Image）**：可选，装了才能出图

## 安装

酒馆 → 扩展 → 安装扩展 → 填入本仓库地址。

## 打开

- 悬浮的 📱（可拖动，可在扩展设置里隐藏）
- 输入框左边的魔棒菜单 →「📱 小手机」
- 扩展设置里的「📱 小手机」面板

生成用的 API 默认是酒馆当前连接的，也可以在小手机的「设置」页里填独立 API。
